# Define and enforce Network Policies

This section covers define and enforce Network Policies. You will study Traffic Isolation And Enforcing Implementations. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Explain directional selection and additive allowances.
- Interpret peer selectors and ports.
- Identify required discovery and backend dependencies.
- Distinguish declaration from demonstrated enforcement.
