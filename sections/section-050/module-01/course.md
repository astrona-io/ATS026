# Ingress Selection And Request Diagnosis

This module develops ingress Selection And Request Diagnosis. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Identify controller class and entry-point requirements.
- Compare host and path matching rules.
- Trace Service backend ports and TLS behavior.
- Distinguish route fallback from application failure.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
