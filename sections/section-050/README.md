# Know how to use Ingress controllers and Ingress resources

This section covers know how to use Ingress controllers and Ingress resources. You will study Ingress Selection And Request Diagnosis. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Identify controller class and entry-point requirements.
- Compare host and path matching rules.
- Trace Service backend ports and TLS behavior.
- Distinguish route fallback from application failure.
