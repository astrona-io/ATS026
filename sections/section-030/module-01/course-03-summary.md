# Summary

Service types express different access relationships, while selectors and ports connect those relationships to application backends. A declared external access type does not guarantee provisioned reachable infrastructure.

Useful traffic still needs ready selected capacity, correct target mapping and permitted network paths. Consider source representation and implementation behavior when reviewing policy or external reachability.

External access combines infrastructure and application routing contracts beyond the Service object itself.
