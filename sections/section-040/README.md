# Use the Gateway API to manage Ingress traffic

This section covers use the Gateway API to manage Ingress traffic. You will study Gateway Classes, Listeners And Routes. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Distinguish infrastructure class, listener and route roles.
- Evaluate namespace attachment and hostname relationships.
- Explain backend references and ReferenceGrant permission.
- Interpret acceptance, programming and reference conditions.
