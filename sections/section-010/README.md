# Understand connectivity between Pods

This section covers understand connectivity between Pods. You will study Pod Addressing And Communication. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Explain Pod address and shared-network behavior.
- Identify network implementation responsibilities.
- Distinguish name resolution from destination connectivity.
- Diagnose listener, address and routing assumptions.
